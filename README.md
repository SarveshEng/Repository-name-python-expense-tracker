# Python Expense Tracker

A simple command-line expense tracker built with Python. It allows users to add expenses, calculate total spending, and view their recorded expenses.

This project is intended for learning Python fundamentals and demonstrating automated code review.

## Features

- Add an expense with a description and amount.
- Store expenses in memory while the program runs.
- Calculate total expenses.
- Display all recorded expenses.

## Requirements

- Python 3.10 or later
- No external dependencies required

## Getting Started

1. Clone the repository.
2. Navigate to the project directory.
3. Run the application:

```bash
python main.py
```

## Example Usage

Add an expense:

```text
Description: Lunch
Amount: 150
Expense added successfully.
```

View expenses:

```text
1. Lunch: ₹150.00
Total expenses: ₹150.00
```
